Persian Subtitles

افزونهٔ غیررسمی Stremio برای زیرنویس فارسی

افزودن به StremioManifestمخزن گیت‌هابحمایت از پروژه

⚡ نصب سریع

برای استفاده از نسخهٔ عمومی، نیازی به نصب Node.js، npm یا تنظیم API Key ندارید.

  1. روی افزودن به Stremio بالا کلیک کنید؛ یا Manifest را در مرورگر باز کنید.
  2. در صفحهٔ Stremio گزینهٔ Install را انتخاب کنید.
  3. پس از نصب، هنگام پخش فیلم یا سریال، بخش زیرنویس‌ها را باز کنید و زیرنویس فارسی را انتخاب کنید.

Manifest عمومی: https://stremio.alirostami.com/subtitles/manifest.json

stremio://: stremio://stremio.alirostami.com/subtitles/manifest.json

📖 معرفی

Persian Subtitles یک افزونهٔ غیررسمی برای Stremio است که برای فیلم و سریال، زیرنویس فارسی را از طریق سرویس SubSource پیدا و در اختیار Stremio قرار می‌دهد.

✨ قابلیت‌ها

  • پشتیبانی از فیلم و سریال
  • جست‌وجوی ترکیبی با Cinemeta و در صورت نیاز IMDb
  • تشخیص فصل و قسمت برای سریال‌ها
  • دریافت و استخراج فایل‌های ZIP و SRT
  • پشتیبانی از کدگذاری Windows-1256 در صورت نیاز
  • Retry و مدیریت خطا
  • CORS و Health Check
  • قابل اجرا روی Cloudflare Workers و Node.js

🛠️ نصب و توسعهٔ محلی

نسخهٔ عمومی آمادهٔ استفاده است. برای توسعه یا استقرار اختصاصی، مخزن را دریافت و وابستگی‌ها را نصب کنید:

git clone https://github.com/alirostami01/Persian-Subtitles.git
cd Persian-Subtitles
npm ci
npm run dev

در استقرار اختصاصی، تنظیمات موردنیاز پروژه از جمله API_KEY سرویس SubSource را در محیط خودتان تعریف کنید. برای نسخهٔ عمومی نیازی به این تنظیمات ندارید.

☁️ استقرار

پروژه از اجرای Node.js و Cloudflare Workers پشتیبانی می‌کند. برای استقرار Worker می‌توانید از Wrangler استفاده کنید:

npx wrangler dev
npx wrangler deploy

🐛 عیب‌یابی

  • اگر افزونه در Stremio دیده نمی‌شود، Manifest عمومی را دوباره باز کنید و نصب را تکرار کنید.
  • اگر زیرنویس خاصی پیدا نمی‌شود، ممکن است آن عنوان در SubSource موجود نباشد یا اطلاعات IMDb آن با عنوان موردنظر تطابق نداشته باشد.
  • برای بررسی سرویس، مسیر /subtitles/health را باز کنید.
