Persian Streams

افزونهٔ غیررسمی Stremio برای پخش فیلم و سریال ایرانی

افزودن به Stremioنصب در Stremio WebManifestمخزن گیت‌هابحمایت از پروژه

⚡ نصب سریع

برای استفاده از نسخهٔ عمومی، نیازی به نصب Node.js، npm یا اجرای سرور روی سیستم خود ندارید.

  1. روی افزودن به Stremio بالا کلیک کنید؛ یا Manifest را در مرورگر باز کنید.
  2. در صفحهٔ Stremio گزینهٔ Install را انتخاب کنید.
  3. پس از نصب، یک فیلم یا سریال را در Stremio باز کنید و streamهای ارائه‌شده توسط افزونه را انتخاب کنید.

Manifest عمومی: https://stremio.alirostami.com/streams/manifest.json

stremio://: stremio://stremio.alirostami.com/streams/manifest.json

📖 معرفی

Persian Streams یک افزونهٔ غیررسمی Stremio برای پیدا کردن و ارائهٔ streamهای فیلم و سریال‌های ایرانی است. نسخهٔ عمومی پروژه روی Cloudflare Workers در دسترس است و Manifest آن مستقیماً قابل نصب در Stremio است.

✨ قابلیت‌ها

  • پشتیبانی از فیلم و سریال
  • جست‌وجو و تطبیق بر اساس IMDb ID
  • تشخیص فصل و قسمت سریال
  • نمایش کیفیت و encoder
  • تشخیص وضعیت زیرنویس فارسی و دوبله
  • پشتیبانی از اعداد فارسی و عربی
  • Fallback برای مسیرهای فصل
  • پشتیبانی از iframe و لینک‌های مستقیم
  • قابل اجرا روی Cloudflare Workers و Node.js

🔌 مسیرهای عمومی

🛠️ نصب و توسعهٔ محلی

نسخهٔ عمومی آمادهٔ استفاده است. برای توسعه یا اجرای اختصاصی، مخزن را دریافت کنید:

git clone https://github.com/alirostami01/Persian-Streams.git
cd Persian-Streams
npm install
npm start

برای اجرای نسخهٔ Worker در محیط توسعه:

npx wrangler dev

در استقرار اختصاصی، BASE_URL و سایر تنظیمات محیطی را متناسب با دامنه و زیرساخت خود تنظیم کنید. این تنظیمات برای استفاده از نسخهٔ عمومی لازم نیست.

🎯 نحوهٔ عملکرد

افزونه هنگام درخواست فیلم یا قسمت سریال، اطلاعات شناسهٔ IMDb را دریافت می‌کند، از منبع جست‌وجوی پروژه برای یافتن عنوان مناسب استفاده می‌کند و پس از تطبیق، streamهای قابل استفاده را با اطلاعاتی مانند کیفیت، encoder، زیرنویس و دوبله به Stremio برمی‌گرداند.

🐛 عیب‌یابی

  • اگر افزونه در Stremio نمایش داده نمی‌شود، Manifest عمومی را دوباره باز کنید و نصب را تکرار کنید.
  • اگر برای عنوانی stream پیدا نمی‌شود، ممکن است آن عنوان در منبع مربوطه موجود نباشد یا تطبیق IMDb آن انجام نشده باشد.
  • برای نصب مستقیم در Stremio Web از لینک نصب در Stremio Web بالای صفحه استفاده کنید.
